Dogar Sajji Restaurant

A restaurant ordering and management web application built to demonstrate online food ordering, cart management, order history, and restaurant administration.

Features

- Responsive restaurant website
- Food menu and shopping cart
- Customer details and checkout form
- Order history and status management demo
- CSV order export
- JSON backup and restore
- Printable receipts that can be saved as PDF
- Demo admin dashboard

Technology

- HTML
- CSS
- JavaScript
- Browser localStorage for prototype order storage

Getting Started

1. Open "index.html" in a web browser, or deploy the project using a static website hosting service.
2. Browse the menu and add items to the cart.
3. Enter customer details and submit a test order.
4. Explore the demo dashboard and export features.

Important Limitations

This repository currently contains a front-end prototype.

- Orders are stored in the browser's localStorage.
- Orders are not yet stored in a shared cloud database.
- The demo admin dashboard is not protected by secure owner authentication.
- Browser storage may be lost if browser data is cleared or the user changes devices.
- JSON backup and restore should be tested carefully before relying on them.

Do not use this prototype for sensitive customer information or live business operations until secure authentication, server-side validation, database access policies, and reliable backups have been implemented.
